# Radboards catalogue scope

The marketing-content project reads only the following public Radboards product collections. Each request is limited to seven products.

| Product type | Collection URL | Products listed during review |
| --- | --- | --- |
| Hoverboards | https://radboards.in/collections/buy-hoverboards-online-for-kids-for-adults | 3 |
| Self Balancing Scooters | https://radboards.in/collections/professional | 1 |
| Handle Hoverboards | https://radboards.in/collections/handle-hoverboard | 1 |
| Electric Unicycles | https://radboards.in/collections/electric-unicycle-euc | 5 |
| E-Scooters | https://radboards.in/collections/electric-kickscooter-for-adults-kickscooter-electric-adults-kids | 2 |

The scraper reads Radboards' public Shopify collection JSON endpoint. It does not require login credentials and does not change any website data.
